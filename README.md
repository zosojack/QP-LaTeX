# Quantum Photonics - Appunti LaTeX

## 📚 Descrizione

Questa repository contiene una versione revisionata e aggiornata degli appunti di **Antony Riccio** per il corso di **Quantum Photonics** dell'Anno Accademico **2025/2026**.

## ✏️ Informazioni di Revisione

- **Autore originale**: Antony Riccio

## 📖 Contenuti

Il documento è organizzato nei seguenti capitoli:

1. **Classical Model of Light**
2. **Polarized States**
3. **Spin Injection**
4. **Experiments with Polarizers**
5. **Quantum Cryptography**
6. **Statistical Properties of Light**
7. **Photon Statistics**
8. **Photodetectors**
9. **Photon Counting**
10. **Photon Antibunching**
11. **Quantization of the Electromagnetic Field**
12. **Vacuum States and Casimir Effect**
13. **Coherent States**
14. **Vacuum State Detection**
15. **Quantum Entanglement**
16. **Optical Tests of Quantum Mechanics**

## 🖼️ Immagini

Le immagini e le figure sono organizzate all'interno delle rispettive sezioni del progetto LaTeX.

## ⚙️ Compilazione

Per compilare il documento:

```bash
latexmk -pdf main.tex
```

Per pulire i file temporanei:

```bash
latexmk -c
```

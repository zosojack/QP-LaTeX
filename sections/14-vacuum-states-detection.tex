\subsection{Detection of quadrature-squeezed vacuum states}\label{sec:vacuum-states-detection}

\subsubsection{Individual quadrature measurement}

Suppose that a light field is sent onto a $50:50$ beam splitter, while a second strong field, called the \textbf{local oscillator} (LO), enters the other input port. \hl{The LO has a large amplitude but the same optical frequency as the signal field}. The two output beams are detected by two photodetectors, and the resulting photocurrents are subtracted by a differential electronics stage. This configuration is called \textbf{balanced homodyne detection}. 
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\linewidth]{images_in_pdf/14-/Grafico_79.pdf}
\end{figure}

We can distinguish two different situations:
\begin{enumerate}
    \item \textbf{No input at the signal port:} the local oscillator is equally split between the two detectors, so classically one expects
    \[
    i_2-i_1=0.
    \]

    However, because photons arrive randomly, each photodetector sees independent Poissonian fluctuations. Subtracting the two photocurrents removes the average signal, but it \hl{does not remove the quantum fluctuations}, so the output still contains shot noise. For an ideal setup, the balanced detector has the same shot-noise level as a single detector measuring the same total optical power.

    \item \textbf{A signal field $E_s$ is present:}
    The beam splitter, produces two beams each with half the initial power, hence a factor of $1/\sqrt{2}$ in the field amplitudes: 
    \begin{equation}\label{eqn:14-beam-splitter-fields}
    E_1=\frac{1}{\sqrt{2}}\left(E_\text{LO}\,e^{i\theta_\text{LO}}+E_s\right),
    \qquad
    E_2=\frac{1}{\sqrt{2}}\left(E_\text{LO}\,e^{i\theta_\text{LO}}-E_s\right).
    \end{equation}

    Here, $\theta_\text{LO}$ stands for the phase of the local oscillator. \hl{The local oscillator is a strong field and can therefore be treated classically, whereas the signal field is weak and must be treated quantum mechanically}. We can decompose it into quadrature components:
    \begin{equation}\label{eqn:14-signal-field-quadratures}
    E_s=E_s^{x_1}+iE_s^{x_2}.
    \end{equation}

    Then the two output fields can be written as
    \begin{align}
    E_1 &= \frac{1}{\sqrt{2}}
    \Big[
        \bigl(E_\text{LO}\cos\theta_\text{LO}+E_s^{x_1}\bigr)
        +i\bigl(E_\text{LO}\sin\theta_\text{LO}+E_s^{x_2}\bigr)
    \Big], \\[0.75ex]
    E_2 &= \frac{1}{\sqrt{2}}
    \Big[
        \bigl(E_\text{LO}\cos\theta_\text{LO}-E_s^{x_1}\bigr)
        +i\bigl(E_\text{LO}\sin\theta_\text{LO}-E_s^{x_2}\bigr)
    \Big].
    \end{align}

    Since the photocurrent is proportional to $|E|^2$, the differential output is
    \[
    i_2-i_1 \propto E_1E_1^*-E_2E_2^*
    \propto E_\text{LO}\Big[\cos(\theta_\text{LO})\,E_s^{x_1}
    +\sin(\theta_\text{LO})\,E_s^{x_2}\Big].
    \]

    Therefore the output is phase-sensitive:
    \begin{itemize}
        \item if $\theta_\text{LO}=0,\pi,2\pi,\dots$, the output is proportional to the amplitude quadrature $E_s^{x_1}$;
        \item if $\theta_\text{LO}=\frac{\pi}{2},\frac{3\pi}{2},\dots$, the output is proportional to the phase quadrature $E_s^{x_2}$.
    \end{itemize}

    \hl{In this way, \textbf{the balanced homodyne detector can measure the signal quadrature that is in phase with the local oscillator.}}
\end{enumerate}

\subsubsection{Vacuum fluctuations}

Let us reconsider the case with no signal at the input port. In that case, vacuum modes enter the signal port and the output is proportional to
\[
i_2-i_1 \propto E_\text{LO}\,E_{\mathrm{vac}}.
\]

In the absence of a signal, the balanced homodyne detector measures the \textbf{vacuum fluctuations}, which set the shot-noise level. In this setting, the detector can be viewed as homodyning the local oscillator with the vacuum field. 

For a squeezed vacuum state instead, one quadrature has reduced noise below this limit, while the orthogonal quadrature has increased noise. This reduction below shot noise cannot be explained classically. 

\question{How can we generate these states?}{%
    Quadrature-squeezed states can be generated by nonlinear optics.
}

\subsection{Generation of squeezed states}

\subsubsection{Quadrature-squeezed vacuum state}

Suppose that a nonlinear crystal is pumped by an intense laser beam with frequency
\begin{equation}\label{eqn:14-pump-frequency}
\omega_p=2\omega,
\end{equation}

while a weak signal field has frequency
\begin{equation}\label{eqn:14-signal-frequency}
\omega_s=\omega.
\end{equation}

This is the \textbf{degenerate parametric amplifier} configuration\footnote{In the degenerate case, the signal and idler fields have the same frequency.}:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\linewidth]{images_in_pdf/14-/Grafico_80.pdf}
\end{figure}

the crystal mixes signal and pump through \emph{difference mixing}, generating an \textbf{idler} beam at frequency $\omega_i$:
\begin{equation}\label{eqn:14-idler-frequency}
\omega_i = \omega_p - \omega_s = 2\omega - \omega = \omega.
\end{equation}

The nonlinear crystal mixes the pump and the signal through a $\chi^{(2)}$ interaction, so that the amplification of the field depends on the relative phase between the input signal and the pump. In the degenerate case, this phase-sensitive process can either amplify or de-amplify a given field quadrature.

\calloutinfo{%
    If no signal is injected, the crystal acts on the vacuum field and converts vacuum fluctuations into a \textbf{squeezed vacuum} state.
}

In the absence of a seed, the only input at the signal port is the vacuum field, whose average amplitude is zero but whose fluctuations are not:
\[
E_{\mathrm{vac}} \sim \sqrt{\frac{\hbar\omega}{2\epsilon_0 V}}.
\]

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\linewidth]{images_in_pdf/14-/Grafico_81.pdf}
\end{figure}

\calloutinfo{%
\textbf{By changing the phase we can modulate the squeeze vacuum states and beat the shot noise:} Changing of phase correspond to select different field quadratures in the balanced homodyne detector. As result, one can observe either reduced noise below the shot-noise limit in the squeezed quadrature or increased noise above it in the conjugate quadrature $\implies$ the quantum noise is redistributed between two complementary quadratures. 
}

This is the basic principle of squeezed-light metrology and is crucial in ultra-sensitive experiments, such as gravitational-wave detection, where reducing quantum noise is essential to measure really tiny changes.
